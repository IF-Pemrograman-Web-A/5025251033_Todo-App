# PEMROGRAMAN WEB (A)

## Deskripsi

Web ini secara simple menampilkan To-Do List pada bagian kiri grid dan detail lebih lengkap serta editor di sebelah kanan. Hal ini memudahkan pengguna untuk mengedit, melihat serta mengerti todolist yang telah mereka buat.
